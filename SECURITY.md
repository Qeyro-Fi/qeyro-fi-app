# Security policy

QEYRO FI app is pre-release software. It has not been independently audited.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

1. Use GitHub's "Report a vulnerability" button on the Security tab of this repository (private advisory).
2. Describe what you found, how to reproduce it, and what you think the impact is.
3. If the issue affects deployed contracts, include the network and addresses.

You will get an acknowledgement within 7 days. We ask for a reasonable disclosure window
(90 days by default) so a fix can be prepared and released before details are public.

## Scope

In scope: code in this repository and its documented behaviour.
Out of scope: third-party wallets, RPC providers, and accounts that do not follow ERC-7579.

## What we promise (and do not)

- We will credit reporters who want credit.
- We make no guarantee of protection against any attack. See the risk disclosures in the documentation.
